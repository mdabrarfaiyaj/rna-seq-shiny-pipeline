# Contributing to rna_seq_shinny_pipeline

Thanks for being interested in this project!

## How to report a bug
- Check existing issues first
- Use the bug report template
- Include your R version and package versions

## How to suggest improvements
- Open an issue to discuss before making major changes
- Explain the biological or technical reason

## Development setup
1. Clone the repo
2. Install R packages: `install.packages(c("shiny", "DESeq2", "ggplot2"))`
3. Run the app: `shiny::runApp("app.R")`

## Code style
- Use tidyverse conventions
- Comment biological interpretations, not just code
