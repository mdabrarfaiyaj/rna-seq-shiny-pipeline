# Security Policy

## About this project

This is an **educational replication project** using publicly available data from published research (Shemer et al. 2020). It is maintained as a learning and portfolio tool, not as production software.

## Best practices when using this code

- Keep R and all packages updated
- Review the code before running it on your system
- Use the provided example data (GSE157234) to verify functionality
- Report bugs as [GitHub issues](../../issues) rather than security reports

## Dependencies

This project depends on:
- **Shiny** — R web framework
- **DESeq2** — Bioconductor package for differential expression
- **ggplot2** — Data visualization

Security issues with these packages should be reported to their respective maintainers:
- **Shiny:** https://github.com/rstudio/shiny/security
- **DESeq2:** https://www.bioconductor.org/
- **ggplot2:** https://github.com/tidyverse/ggplot2/security
